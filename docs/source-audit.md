## Owner-directed v3 scope

The owner subsequently clarified: Zoomigo is alpha; legacy data migration is unnecessary. Build a high-quality independent v3 and optimize integration ease. The migration column above documents potential differences found during the audit, not a parity promise or required migration backlog. No migration tools, Canvas fallback or dual runtime will be built. New consumers start with versioned v3 content and app-owned policies. Zoomigo can adopt the new contract directly behind a clean route boundary.
